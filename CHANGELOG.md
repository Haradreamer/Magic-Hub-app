# Changelog

## 1.0.0 — Initial stable release

- First Android release of Magic Hub.
- Google Edge / Discover launch from the HONOR home screen.
- Google Lens and Circle to Search gesture zones.
- Independent gesture zone sizing, positioning and hold controls.
- Independent **Avoid keyboard conflicts** switches for Edge, Lens and Circle.
- Optional Shizuku-based YOYO controls and setup instructions.
- Nine interface language modes and first-launch language selection.
- Light and dark themes; streamlined interface without developer diagnostics.
- R8 code obfuscation, resource shrinking, Android APK digital signature and SHA-256 integrity verification.

Note: Real-device compatibility varies by HONOR model and MagicOS build.
