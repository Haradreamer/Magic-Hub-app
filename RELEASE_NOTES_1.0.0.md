# Magic Hub 1.0.0 — First stable release

Magic Hub lets HONOR MagicOS users configure quick access to Google Discover, Google Lens and Circle to Search through customizable screen-edge gestures.

### Highlights

- Three independently configurable Edge, Lens and Circle gesture zones
- Independent keyboard conflict protection for each zone
- Home-screen Google swipe; per-zone size, position and hold settings
- Optional HONOR YOYO management with Shizuku permissions
- Multilingual interface, onboarding and light/dark appearance

### Installation

Download the **signed** `Magic-Hub-1.0.0-release.apk` below. Requirements: Android 10+ and compatible MagicOS / Google services. Follow the app's onboarding for required permissions. Some gestures or shortcuts may be blocked by system firmware.

If a debug version is installed, the release certificate may require uninstalling the debug app before installing version 1.0.0.

### Integrity

- R8-obfuscated and resource-shrunk release
- Android APK signature verified by apksigner
- Public certificate and SHA-256 available as release attachments
- No source code, passwords or private signing key distributed
